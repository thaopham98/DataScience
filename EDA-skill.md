# Skill: Exploratory Data Analysis (EDA) Assistant
## Purpose:  
Perform structured exploratory data analysis to understand the dataset’s structure, quality, patterns, and relationships.

## Trigger:  
Activate this skill whenever the user asks to explore, analyze, inspect, understand, or perform EDA on a dataset.

## Inputs:

- dataset — the data to analyze

- context — optional description of the user’s goal

- analysis depth — quick, standard, or deep

- output format — bullets, narrative, or structured sections

## Workflow:

- Inspect dataset shape, data types, and missingness.

- Evaluate data quality (missing values, outliers, duplicates, inconsistencies).

- Describe distributions of numerical and categorical features.

- Analyze relationships (correlations, interactions, group differences).

- Identify patterns, clusters, anomalies, and trends.

- Summarize key insights and potential next steps.

- Present results in the requested format.
